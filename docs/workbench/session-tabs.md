# 会话标签与文件区

工作台的导航职责：**左侧只放文件，会话都在顶部标签条里**。本轮把原先混在侧栏的「会话 / 文件 / 庭审」三页签拆开，并让文档状态跟随标签。

## 结构

- 侧栏：当前工作区的文件列表、上传/新建文档、仅搜当前空间文件的搜索框、空间切换胶囊（顶部）与底部工具入口。会话列表与全局搜索不再出现在侧栏。
- 标签条（主区顶行）：`[会话标签…] [+]`，右端固定两个按钮——会话历史下拉、会话全屏 ⇄ 并排。标签形状与工作台其他控件同一档：`--radius-sm`（10px）圆角矩形、`--wb-control-size`（32px）等高，不使用药丸形（与行、按钮、搜索框一致）。
- 标签与会话一一对应：`/conversation/:id`、`/court/:id` 各占一个标签；`/home`、`/project/:id` 是该空间的「新会话」标签。
- 文档没有标签：从侧栏打开，每个标签同时只显示一篇文档，切换标签即切换文档，切回即恢复（状态持久化在 `lawver.tabs:<user>`）。

## 规则

1. **一个会话只占一个标签**，且标签内选会话分两种情况：
   - 目标**已在某个标签里打开**（历史下拉、首页最近会话、分支创建）→ 跳到那个标签，不新增、不复制。
   - 目标**还没打开** → **由当前标签接管**：标签留在原位，换掉它显示的会话，并清掉它原先的文档（文档跟随会话）。这正是历史下拉在已打开标签里的语义——不再多开一个标签。
   - 深链接/首次加载没有"当前标签"可接管，按目标所属空间补一个标签。
2. **新建标签不关当前标签**：`+` 打开该空间的「新会话」标签；空间已有空白标签时聚焦它，不再叠加。
3. **会话全屏 ⇄ 并排**：右上角按钮收起文档窗格时文档保持打开（`docHidden`），侧栏文件选中态同步清除；文档窗格上的「收起文档」做同一件事。
4. **删除/归档会话即关闭标签**：焦点落到右邻标签，无右邻取左邻；关掉最后一个标签回到新会话标签。
5. **后台任务有徽标**：非当前标签的会话若在运行，按 5 秒低频拉运行状态；完成或失败在标签上留未读圆点，切回该标签即清除。当前标签的运行由事件流轮询驱动，两者不重复请求同一任务。
6. **拖拽排序与右键菜单**：标签可拖动排序（FLIP 动画）；右键提供重命名、收藏、归档、复制会话链接、关闭、关闭其他、移入回收站。不做中键关闭与双击重命名，也不绑定 Ctrl+W / Ctrl+Tab（浏览器占用，不可靠）。

## 版面几何（对齐 Quote 参照）

- **侧栏不是卡片**：直接坐在画布上，无边框、无圆角、无阴影（桌面 ≥1024px 明确清掉这些声明）。
- **主区只有一张 sheet**：`.wb-sheet` 从左（距侧栏 4px）贴到窗口右缘（10px 内边距），上 8px、下 10px 圆角白卡。**标签行（标签 + ＋ + 会话历史 + 会话全屏）在这张 sheet 内部**，不再单独占一行浮在画布上。
- **分栏是 flex 而不是 grid**：文档列宽度由 `motion` 驱动的 `flex-basis` 给出（`flex: 0 0 auto`），右栏（会话或首页）`flex: 1 1 0` 吃剩余宽度；两栏之间是 11px 命中区 + 1px 分隔线的 `.wb-resizer`（拖动时把过渡时长设为 0，避免逐帧动画拖沓）。
- **文档区底色随 sheet**：`.wb-document-scroll` 不再自带画布灰，整块与 sheet 同为白色。

## 面板过渡（展开/收起）

三个状态都是**连续变宽**而不是瞬时切换（对应参照视频里约 400ms 的缓动）：

| 状态 | 文档列 flex-basis | 右栏 |
| --- | --- | --- |
| 并排 | `docPercent%`（默认 65%，随拖动改） | 剩余宽度 |
| 仅文档 | `100%` | 隐藏（`display:none`，**保持挂载**以免丢滚动与庭审状态） |
| 会话全屏 | `0%` + `opacity: 0` | 占满 |

实测（1512×950）：收起 811→776→647→522→396→121→0 与展开 811→1035→1183→1227→1248 都是 ~400ms、逐帧连续。文档列挂载时不使用 `initial={false}`，这样首次打开文档也有从 0 展开的进场。

### 文档内容不随动画重排（卡牌式覆盖/展现）

外层 `flex-basis` 变化时，**文档的排版宽度必须钉住**，否则文字会随着面板变窄逐帧重排，看起来像"布局崩溃"。做法：

- `.wb-sheet` 声明 `container-type: inline-size`，文档内层 `.wb-document-pane` 用 `min-width: calc(var(--wb-doc-percent) * 1cqw)` 固定排版宽度（`--wb-doc-percent` 由 `WorkspaceLayout` 按分栏比例注入，拖动后同步）。
- 外层 `.wb-document-column` 保持 `overflow: hidden`：收窄时只是把右侧裁掉，文档内容一动不动，视觉上就是被对话面板"盖住"；展开时再"露出来"。
- 纸张 `max-width` 收到 800px：并排档（65cqw）与仅文档档（100cqw）下纸张宽度一致，档位切换也不会重排。

实测收起过程：面板 811→460→141→45→13→2→0，而**纸张宽度全程 763px 不变**，即文字零重排。

### 右栏窄档自适应

右栏（会话或首页）自己按宽度自适应，与窗口宽度解耦：`.wb-right-pane` 也是容器（`container-type: inline-size`），`@container (max-width: 620px)` 下首页缩小字号与内边距、卡片单列、chips 横向滚动，会话收紧内边距并隐藏免责声明的小字号。这样"文档 + 首页"这种窄档组合也不会把首页内容挤出面板。

**右侧内容包在 `.wb-right-pane` 里**：会话/首页都挂在这个容器下，它负责吃剩余宽度，仅文档模式下整块 `display:none`。

## 换空间（换台动画）

标签按空间隔离。切换工作区时，当前空间的标签作为一组向左滑出、从侧栏下方穿过消失，新空间的标签从右侧进入并左移停靠（`AnimatePresence mode="wait"` + 定时缓动；`prefers-reduced-motion` 下退化为淡入淡出）。标签组滑出时用视口的负边距 + `overflow: hidden` 与侧栏边缘对齐，所以是「没入侧栏」而不是在侧栏旁提前消失。

## 首页（新会话标签）

问候语 → 工作建议（`POST /api/workbench/suggestions` 按当前空间材料标题生成，`换一批` 强制重生成，失败或离线退回本地静态建议池）→ 输入框 → 最近会话 →（个人工作区）项目陈列。进入项目空间时隐去项目陈列。

## 服务端配合

- `GET /api/workbench/search` 新增 `kind` 与 `space`：侧栏搜索只搜当前空间的文档，且结果不再携带正文。
- `POST /api/workbench/suggestions`：素材只取最近 6 篇文档与 4 条会话的**标题**，20 秒超时，任何失败都返回静态建议而不是报错；进程内按（账号、空间、素材指纹）缓存 12 小时，降级结果缓存 5 分钟。
