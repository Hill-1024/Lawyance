# 项目庭审整合

模拟法庭是项目下的特殊会话模式。项目树与项目工具栏提供创建入口，左下角不再保留独立入口。工作台通过 `?project=…&court=…` 打开庭审，保留导航、会话标签与可停靠视窗（详见 [session-tabs.md](./session-tabs.md)：庭审与普通会话一样占一个标签，文档不再有独立标签条）；旧 `/court` 链接在新版工作台中重定向到此模式。准备界面使用公开案卷、私有备庭、项目材料三个页签；过程使用连续会话流，案卷通过会话内面板查看。

## 材料与角色边界

选择项目后自动读取该账号、该项目下的普通会话正文，不读取其他庭审的私有笔记、工具日志或其他项目。每份材料标记来源、版本、更新时间，AI 回复标记为待核验草稿。首轮是原文汇集，不宣称自动完成案情事实抽取。

最多收录 40,000 字，每个会话最多 10,000 字。超限时明确标记节选与遗漏数量。正文自动填入可编辑私有备庭材料；用户必须填写公开案情或显式选入公开材料后才能创建。私有笔记沿用我方代理/复盘员权限，法官与模拟对方不接收这些内容。创建后冻结收集结果，后续项目会话不会自动修改已开庭案卷。

## 保存与恢复

- `GET /api/workbench/projects/{id}/court-context`：账号与项目隔离的材料快照。
- `PUT /api/workbench/courts/{id}/snapshot`：项目归属校验、预期修订号、重复请求去重。
- `GET /api/workbench/courts`：轻量目录，不包含私有正文；详情或 `include_session=true` 才返回账号所属的完整记录。
- 项目庭审包含于工作台备份，旧独立庭审继续使用 IndexedDB。
- 自动推进开关不在恢复时重启，用户必须明确继续执行。
- 同设备待同步副本存于账号隔离缓存。冲突不覆盖云端，可导出恢复副本后选择云端版本。
- 保存状态展示进行中、已保存及错误；离开页面会尝试提交最终快照。

## 验证

27 项工作台/庭审后端测试通过，覆盖项目与账号隔离、角色上下文、版本冲突、重复请求与恢复时禁止自动执行。隔离 QA 项目的浏览器验证覆盖创建、来源收集、私有笔记、项目树重入、刷新恢复及一次真实模型首轮庭审。检查 390px 手机视口；未做 Android 实机回归或完整多阶段庭审验收。


## 内嵌会话与动效复核

- 浏览器验证已有庭审恢复、项目内创建入口、公开/私有准备页签、文档并排及打开文档时发言草稿保留。
- 390px 视窗验证会话/文档面板切换，无横向溢出；桌面实际拖动庭审视窗到右侧成功。
- 复用 legacy WorkflowStatusIcon 的转圈和描边勾选；减少动态效果时停止动画并保持勾选可见。
- 设置弹窗、项目展开、候选列表及布局菜单采用短过渡；停靠使用边缘提示和半透明落位预览。
- 本轮未重新执行完整多阶段模型庭审或 Android 实机测试。


## 工作台专用庭审界面

`src/workbench/CourtConversation.tsx` 直接复用 `useCourtSession`，不嵌入旧 `CourtPage`、角色舞台或旧输入面板。独立设计材料摘要、阶段信息、角色发言、案卷页签和输入区；文档文字选区可作为待发送的公开引用。保留角色隔离、发言队列、自动推进、我方代理、分支和撤回。

移除桌面整条工作台/项目面包屑顶栏，文件与布局操作移至侧栏（侧栏现为纯文件区，会话入口在标签条，见 [session-tabs.md](./session-tabs.md)）；手机导航按钮合入会话标签条左端，文档与会话在窄屏仍为互斥面板（同一枚「会话全屏 ⇄ 并排」控制）。桌面并排与 390px 手机视窗已复核，新的虚构庭审创建、云端恢复及一次真实模型法官发言通过。保存成功只更新庭审目录中变化的条目，避免每次快照保存触发全量目录请求。
