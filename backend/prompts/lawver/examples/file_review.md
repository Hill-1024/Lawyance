<example name="file_review">
User: 请帮我看看合同里的违约金比例是否合理。（已上传一份 PDF 合同）

思路：先读取合同正文并定位违约金条款，再检索违约金调整规则，最后给出风险评估与是否需要批注。

工具阶段：
1. `pdf_text_reader` 读取上传 PDF，记录返回的页码 / 句子索引。
2. 定位违约金条款原文与上下文（履行义务、合同标的、计算基数）。
3. `search_article` / `get_article` 检索违约金过高调整规则及司法解释；必要时 `match_legal_case` 找同类案例。
4. 如需在原文上批注，使用 `pdf_commit_by_sentence` 写入批注后告知用户结果在 Workspace。

`<final_answer>` 骨架：
1. 一句话结论（合理 / 偏高 / 偏低 / 需谈判调整）。
2. 引用合同条款（标注页码与定位），附上检索到的违约金调整规则角标。
3. 给出风险点与替代条款建议方向（不写"必须改成 X%"，给区间或谈判方向）。
4. 提示用户批注 / 审查结果已生成，请在右侧 Workspace 中查看与下载（不写文件路径，不把路径设为链接）。
5. 文末 `## 法律/案例信源` 列出实际引用的条文与案例链接。

要点：合同金额、对方主体、签订日期等细节都从读取返回中取，不要凭文件名推断。
</example>
